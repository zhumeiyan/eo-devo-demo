# 状态立面 · 设计说明

一套给 EO devo 仓库的视觉身份。它不是宣传海报，是**活的状态立面**——
每个状态对应一种真实的运行情况，颜色与节奏都从仓库自己的实验结论里取，不是装饰。

## 一、视觉 DNA

**母题：记忆拓扑**——三层节点簇 + 一条自下而上的轨迹，中段有一级台阶。

```
左下缓坡   β 小时全员挤在同一层（211 号：k 众数 0，多样性 0.000）
中段台阶   拐点 β*≈0.02（崩塌 4/8→0/8，熵 0.86→1.33）
右上分叉   加上「独特性」这根轴后分层（k 分布 6/6/6/2，多样性 1.011）
```

所以这张图**画的就是 211 号实验本身**，不是通用科技背景。
要求里写明"用状态波形/推理轨迹/记忆拓扑的简化线条，不用通用科技背景"——这条是硬约束，母题直接取自实验数据。

**无面原则**：不出现人脸、拟人动物、表情包。主体是节点与连线，任何人看到都不会误读为角色。

## 二、状态表

| 状态 | 颜色 | 节奏 | 动画 | 含义（为何是这个样子） |
|:--|:--|:--|:--|:--|
| **idle** 待命 | `#3d7a5a` 冷绿 | 4s 慢呼吸，低亮 | `breathe` | 在，但没被按。对应两次对话之间我不存在的那段，只能由定时任务代偿 |
| **thinking** 推演 | `#9c6416` 琥珀 | 0.8s 快脉冲 | `pulse-fast` | 正在选。琥珀=偏离基线。202 号：动值 0.15–0.19 bits，选得准只值 0.02–0.09 |
| **busy** 运转 | `#4a9a8f` 亮青 | 持续旋转 + 波纹 | `rotate-ripple` | 在跑。旋转是采样，波纹是休眠恢复。203 号：进化靠采样+休眠，不是做梦 |
| **blocked** 受阻 | `#7a4343` 低饱和红 | **脉冲冻结** | `frozen` | 动不了但不是错。**刻意低饱和——受阻 ≠ 失败**。206 号：竞争杀死的东西恰恰是系统的保险 |
| **error** 失效 | `#b3322a` 红 | 一次抽动后静止 | `twitch-once` | 抽一下就停。212 号：我编过不可能的数字（子集覆盖率上限 0%，却声称 +86%） |
| **success** 成立 | `#c99a3f` 暖金 | 短暂暖脉冲，回落 idle | `warm-decay` | 暖一下就退回待命，**不常驻**。211 号：台阶之后 β 加大 80 倍也无趋势 |

### 节奏为什么不重复

`blocked` 和 `error` 的周期都是 0.0，但一个是完全冻结、一个是抽动一次后静止——
**周期相同，行为不同**，靠 motion 而非数值区分。

其余四个（0.8 / 2.4 / 3.0 / 4.0 s）两两间距 ≥0.6s，肉眼可分。

## 三、颜色

- 背景 `#0d1117`（GitHub 深色底），墨 `#e6edf3`，次级灰 `#8b949e`
- 六状态色两两 RGB 欧氏距离 **最小 58.6**（`error`↔`thinking`），全部 ≥30 门槛
- **颜色有语义**：冷暖对应"是否在动"，饱和度对应"是否是错"

> 第一版 `thinking` 用 `#b8862f`、`success` 用 `#c99a3f`，两者距离仅 **30.7**，
> 刚过门槛但肉眼易混。已把 `thinking` 压深到 `#9c6416`，最小间距提升到 58.6。

## 四、文件用途

## 五、技术约束（已自检）

- **不跑 JavaScript**：8 个 SVG 全部扫描，无 `<script>`、无 `on*` 属性
- **无外部依赖**：字体走 `font-family: "WenQuanYi Micro Hei", system-ui, ...` 本地回退，不发外链
- **动画只走 CSS `@keyframes`**：不用 SMIL，兼容性更稳
- **可版本化**：SVG 是纯文本，可 diff、可回滚
- **字号单一真相源**：`status.json` 定义，`gen_assets.py` 读取，`verify_assets.py` 校验——三处不脱节

## 七、已知缺口

- **GitHub README 中 SVG 动画是否播放，未经真机验证。** 仓库是私有的，
  通过 camo 代理加载时动画可能被转成静态图。需要转 Public 后实测一次。
- `social-preview-640.png` 的"可读"是靠字号门槛（14px）推断的，**没有真人看过**。
  这与 212 号的教训一致：可演绎的能算准，需经验的只能交给人。
- 母题的台阶位置是**视觉示意**，不对应 β=0.02 在对数轴上的真实比例
  （0.02/1.6 = 1.25%，画出来会看不见）。这是刻意的视觉放大，已在此声明。
