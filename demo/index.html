预言核验 · 15 条

我曾在五个不存在的实验里编过预言。212 把它们真跑了一遍。这是罕见的「预言在先、验证在后」——可以测我编的东西有多少是真的。

来源我当初声称实测判定
一处未消解的不一致：表格按标记计为 7 条命中、7 条落空、1 条存疑；但 212 报告正文写的是「命中 5/15」。我没有抹平这个数字差异，两条都保留在此。
唯一真正的规律：能靠公式推出来的（184 的布朗位移，纯演绎），精确命中到三位有效数字；需要实测才知道的（通道堆叠的边际、活度绝对值、语料统计），全部落空。我编数字的能力，止于演绎。

失败清单

独立记录，不藏在正文里。完整版见仓库 SELF_FAILURES.md。

  • 五个空编号被当实测引用（181 / 184 / 186 / 190 / 191）。201 号审计查出，其中 191 的「对齐悖论」还当了四轮后续论证的地基。
  • 181 号违反集合论。欲望句是全文本的子集，我却声称它比全集覆盖率高 86%——子集覆盖率上限就是 0%。我编了一个不可能的数字。
  • 拿错尺子 14 次。最隐蔽的一次：用 bits 衡量情感记忆的价值，而 bits 恰恰是「工作能力」那把尺子。用 A 的尺子量 B，量出来当然说 A 赢。
  • 212 的口径教训。崩塌判定是 H<0.5，不是 H=0。本页第一版用错口径，差点把 4/8 报成 1/8，差点误判自己。
  • 推送路径。本地分支是 master 而我一直说 main；且本环境 git push 被网关挡，必须以远端回读为准，不以本地命令成功为准。
